Проект API тестов сайта https://stellarburgers.nomoreparties.site/login

Проект в себя включает тестирование функциональностей:

Создание пользователя:
1. Создать уникального пользователя
2. Создать пользователя, который уже зарегистрирован
3. Создать пользователя и не заполнить одно из обязательных полей

Логин пользователя:
1. Логин под существующим пользователем
2. Логин с неверным логином и паролем

Изменение данных пользователя:
1. С авторизацией
2. Без авторизации

Создание заказа:
1. С авторизацией,
2. Без авторизации,
3. С ингредиентами,
4. Без ингредиентов,
5. С неверным хешем ингредиентов.

Получение заказов конкретного пользователя:
1. Авторизованный пользователь,
2. Неавторизованный пользователь.


Структора проекта:

test - папка с тестами
conftest - файл конфигурации
data - данные
urls - ссылки и урлы


Зависимости:

pytest
requests
Язык - Python
